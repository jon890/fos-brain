# aria-label 이 시각 라벨을 덮는다

## 증상

버튼에 눈에 보이는 글자와 `aria-label` 이 함께 있고 둘의 내용이 다르면,
접근 가능한 이름이 `aria-label` 로 완전히 바뀐다.
음성 조작으로 화면에 보이는 글자를 불러도 그 버튼에 닿지 않는다(WCAG 2.5.3 Label in Name).

## 실제 사례

`memoryAtlasView.tsx` 의 「전체 보기」 버튼이 `aria-label="지도 이동과 배율을 처음 상태로"` 를 가져,
「전체 보기」 로는 음성 조작이 버튼을 찾지 못했다.
바로 옆 「중앙 정렬」 은 `aria-label` 없이 시각 라벨을 그대로 써 규칙도 엇갈렸다.

## 고치는 방법

설명은 `title` 로 준다. 시각 라벨이 그대로 접근 가능한 이름이 된다.
접근 가능한 이름을 굳이 늘려야 하면 시각 라벨을 앞에 포함시킨다.

## 검출

```bash
rg 'aria-label="[^"]+"' --glob '*.tsx' -A 3 | rg -B 3 '^\s*[가-힣]'
```

글자를 가진 요소에 `aria-label` 이 붙은 자리를 훑는다.
아이콘만 있는 버튼은 `aria-label` 이 맞으므로 결과를 사람이 가른다.
