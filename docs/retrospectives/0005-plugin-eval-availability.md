# 설치된 CLI에서 plugin eval을 실행할 수 없었음

## 관찰

Phase 02가 반복 가능한 행동 평가에 쓰려던 `claude plugin eval` 명령은 설치된 Claude Code 2.1.243에서 early access 비활성 상태로 종료됐다.
평가 사례를 만드는 `init --bare` 단계도 같은 이유로 실행되지 않았다.

## 원인

계획은 CLI 도움말에 명령과 옵션이 보인다는 사실만 확인했다.
현재 계정과 세션에서 해당 기능을 실제로 실행할 수 있는지는 사전 검증하지 않았다.

## 영향

기준 버전과 새 버전의 행동을 비교하는 원래 검증 명령을 그대로 실행할 수 없었다.
활성화 방법을 추측해 우회하면 다음 세션에서 다시 실행할 수 있다는 보장도 없었다.

## 대응

실행 가능한 native subagent 평가로 기준 버전과 새 버전을 비교한다.
평가 정의는 skill-creator 스키마로 저장하고, 결과 JSON은 저장소의 결정적 검사기로 검증한다.
Codex 재실행기는 기준판과 현재판을 임시 복사본에서 읽기 전용으로 평가하고 원문, 별도 채점, 결과, 전후 파일 hash를 함께 남긴다.
Claude Code 마켓플레이스는 제거하면 설치 목록도 함께 정리되는 동작을 확인했다.
설치본을 유지한 채 원래 경로로 돌릴 때는 같은 이름의 마켓플레이스를 제거하지 않고 `marketplace add`로 경로만 갱신했다.

## 검증

기준판과 새 플러그인의 brain-add와 brain-curate를 독립 실행하고 별도 검증자가 12개 기대값을 채점했다.
기준판은 11개, 새 플러그인은 12개를 통과했다.
네 결과 JSON은 저장소 검사기를 통과했다.
재실행기 경로도 실제로 실행해 두 격리 복사본의 평가 전후 hash가 같고 현재판의 12개 기대값이 통과함을 확인했다.
Codex CLI와 Claude Code의 설치 버전은 0.2.0이고 소스와 두 캐시의 공용 정책 hash가 같았다.
두 마켓플레이스 주소도 원래 main 경로로 복원했다.

## 배운 점

CLI 도움말에 표시되는 실험 기능은 계획 전에 가장 작은 실제 명령까지 실행해 사용 가능성을 확인해야 한다.

## 후속

Claude Code가 plugin eval을 정식 제공하면 repo-local 평가 결과와 비교해 전환 여부를 판단한다.
