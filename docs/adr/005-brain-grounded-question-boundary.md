# ADR-005: Brain 근거 질문은 같은 출처 BFF로 제한한다

- 상태: 승인
- 날짜: 2026-08-26

## 맥락

Memory Atlas에서 질문할 수 있어야 하지만 첫 버전은 일반 대화형 에이전트가 아니라 Brain에 저장된 근거를 읽고 답하는 단일 질문 기능이어야 한다. 브라우저에 모델 키나 내부 검색 주소를 전달해서도 안 된다.

## 결정

- 브라우저는 같은 출처의 `POST /api/brain/ask`만 호출한다.
- BFF는 public·private wiki 검색 결과만 모델에 전달한다.
- 도구 호출, 대화 저장, 다중 턴 문맥은 비활성화한다.
- 한 질문에는 근거 문서를 최대 6개, 합계 32 KiB까지만 전달한다.
- 응답의 출처 목록은 모델 출력이 아니라 서버가 선택한 검색 결과에서 만든다.
- 공개 저장소는 BFF, API 계약과 단위 테스트를 소유한다.
- 모델 프로필, 비밀값, 컨테이너 연결, 프록시와 배포 검증은 private 인프라 저장소가 소유한다.

## 결과

- 브라우저에는 모델 키와 내부 검색 주소가 노출되지 않는다.
- 답변이 Brain 근거 범위를 벗어나면 명시적으로 답변할 수 없다고 반환한다.
- 운영 환경을 공개하지 않고도 질문 기능을 독립적으로 개발하고 검증할 수 있다.

## 검토한 대안

- 브라우저에서 모델 API를 직접 호출하는 방식은 비밀값 노출 때문에 채택하지 않았다.
- 일반 목적 에이전트를 연결하는 방식은 읽기 전용 단일 질문 범위를 벗어나므로 채택하지 않았다.
- 모델이 출처를 임의로 생성하게 하는 방식은 실제 검색 근거와 어긋날 수 있어 채택하지 않았다.
