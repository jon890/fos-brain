# ADR-004: qmd 검색은 애플리케이션과 분리한 HTTP 경계를 사용한다

- 상태: 채택
- 날짜: 2026-08-26

## 맥락

qmd는 네이티브 모듈과 모델 캐시를 사용한다. 이를 질문 애플리케이션과 같은 실행 단위에 넣으면 런타임 버전, 색인 수명 주기, 메모리 사용량이 서로 강하게 결합한다. 반대로 qmd의 인증 없는 HTTP 인터페이스를 외부에 노출하면 개인 지식 검색 경계가 사라진다.

## 결정

- qmd는 내부 HTTP 서비스로 분리한다.
- 공개 저장소는 `/query` 요청·응답 검증, 허용 컬렉션, 실패 시 축소 검색 계약을 소유한다.
- 실제 이미지, 컨테이너 네트워크, 마운트, 색인 경로와 갱신 절차는 private 인프라 저장소가 소유한다.
- public wiki, public raw, private wiki 컬렉션 구분을 유지한다.
- Brain 근거 질문에는 public·private wiki만 허용하고 private raw는 사용하지 않는다.

## 결과

- qmd를 사용하는 애플리케이션은 네이티브 모듈과 모델 캐시를 직접 관리하지 않는다.
- 운영 환경은 qmd를 외부에 게시하지 않고 내부 호출만 허용할 수 있다.
- 애플리케이션 계약과 운영 배치를 서로 독립적으로 검증할 수 있다.

## 검토한 대안

- 에이전트 이미지에 qmd를 직접 설치하는 방식은 런타임과 모델 캐시 결합이 커서 채택하지 않았다.
- 브라우저가 qmd를 직접 호출하는 방식은 인증 없는 검색 인터페이스를 노출하므로 채택하지 않았다.
- 운영 구성을 공개 저장소에 예시로 유지하는 방식은 실제 구조를 추측할 단서를 남기므로 채택하지 않았다.
