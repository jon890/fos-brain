# ADR-007: 지식 유입 정책을 플러그인의 단일 계약으로 둔다

- **결정**: 저장 가치, 목적지, 공개 범위를 판정하는 정책을 fos-brain 플러그인의 공용 참조 문서 하나에 둔다.
  brain-add와 brain-curate는 저장 전에 이 정책으로 모든 후보를 판정하고, brain-lint는 같은 정책으로 기존 지식의 유지 가치를 점검한다.
  회사 내부 지식은 public과 private 어느 쪽에도 저장하지 않고 nbrain으로 보낸다.
- **맥락**: 기존 프로젝트 지침과 스킬마다 durable 지식 기준이 흩어져 있어 다음 세션에서 서로 다른 기준을 적용할 수 있다.
  raw를 먼저 보존하는 흐름은 최종적으로 제외할 정보까지 개인 brain에 남길 수 있다.
  의미 적합성은 출처와 사용자 맥락을 함께 봐야 하므로 정적 점수만으로 안전하게 판정할 수 없다.
- **대안 기각**: 각 스킬에 기준을 복사하는 안은 문구가 달라질 때 계약이 어긋나므로 기각한다.
  모든 후보를 raw에 먼저 저장하고 wiki만 선별하는 안은 회사 자료와 일회성 소스가 raw에 남으므로 기각한다.
  자동 점수로 저장 여부를 결정하는 안은 개인적 의미와 미래 사용 사례를 설명하지 못하므로 기각한다.
- **트레이드오프**: 소스 저장 전에 후보 판정과 사용자 미리보기가 필요해 적재 단계가 하나 늘어난다.
  대신 다음 세션과 여러 스킬이 같은 기준을 사용하고, 제외한 정보가 원본 저장소부터 쌓이는 문제를 막는다.
