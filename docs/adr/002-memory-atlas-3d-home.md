# ADR-002: 전체 지식 탐색은 홈 전용 3D Memory Atlas가 담당한다

- **결정**: 루트 홈에 실제 3D 회전과 카메라 제어가 가능한 Memory Atlas를 제공한다.
  `3d-force-graph`와 `three`는 홈에서만 동적으로 불러오고, 일반 문서의 로컬 그래프는 기존 D3와 PixiJS 구현을 유지한다.
- **맥락**: 기존 오른쪽 그래프는 현재 문서의 인접 관계를 읽는 데 적합하지만 전체 지식을 필터와 여러 배치로 탐색하기에는 화면과 조작 범위가 작다.
  참고한 Second Brain처럼 그래프를 주 화면으로 만들려면 깊이와 카메라 조작이 필요하지만, 모든 문서에 3D 실행 비용을 부과할 이유는 없다.
- **대안 기각**: 기존 PixiJS 그래프를 전체 화면으로만 키우는 안은 새 의존이 없지만 실제 3D 회전과 깊이 탐색을 제공하지 못한다.
  모든 문서 그래프를 3D로 교체하는 안은 읽기 화면의 실행 비용과 회귀 범위를 불필요하게 늘린다.
  그래프 전용 별도 서비스는 정적 Quartz의 단순한 배포와 public/private 산출물 경계를 깨므로 기각한다.
- **트레이드오프**: 홈에서 Three.js 묶음을 추가로 내려받고 WebGL 성능을 관리해야 한다.
  대신 지연 로드, 모바일 노드 제한, 움직임 줄이기, 실제 HTML 검색과 상세 목록을 통해 비용과 접근성 위험을 제한한다.
