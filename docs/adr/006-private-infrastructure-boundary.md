# ADR-006: 운영 구성은 private 인프라 저장소가 소유한다

- 상태: 채택
- 날짜: 2026-08-27

## 맥락

공개 저장소의 배포 파일과 운영 기록에는 비밀값이 없더라도 호스트 경로, 서비스 구성, 내부 연결과 복구 절차가 드러날 수 있다. 이 정보는 애플리케이션을 이해하거나 재사용하는 데 필요하지 않다.

## 결정

- 공개 저장소에는 애플리케이션 코드, 일반 API 계약과 로컬 검증만 둔다.
- Compose, 프록시, 자동화 러너, 모델 프로필, 호스트 경로와 운영 검증은 private 인프라 저장소가 소유한다.
- 운영 자동화는 private 인프라 저장소의 검증된 커밋을 가져와 저장소의 진입 스크립트를 실행한다.
- 비밀값은 공개·비공개 Git 어느 쪽에도 저장하지 않고 서버의 권한 제한 파일이나 자동화 도구의 비밀값 저장소로 관리한다.
- 현재 공개 Git 이력의 재작성은 이관 범위에 포함하지 않는다. 이관 검증이 끝난 뒤 별도 승인으로만 수행한다.

## 결과

- 공개 저장소만 보고 실제 홈서버 구조를 직접 재구성하기 어려워진다.
- 운영 변경은 private 저장소에서 검토·복구·감사할 수 있다.
- 애플리케이션 변경과 운영 배포의 책임 및 PR을 분리할 수 있다.

## 검토한 대안

- 자동화 도구 화면에 스크립트를 직접 저장하는 방식은 변경 이력과 재현성이 부족해 채택하지 않았다.
- 공개 저장소에 값만 가린 배포 예시를 두는 방식은 구조 정보가 계속 남아 채택하지 않았다.
- 이관과 동시에 공개 이력을 재작성하는 방식은 복구가 어렵고 협업 브랜치를 깨뜨릴 수 있어 채택하지 않았다.
