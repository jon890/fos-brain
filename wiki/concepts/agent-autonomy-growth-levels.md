# AI 에이전트 자율 성장 단계

AI 에이전트의 자율성은 단순 응답에서 세션 간 학습, 자기 헌법 수정까지 단계적으로 나뉠 수 있다.
GNOSIS 발표는 이를 L0부터 L5까지의 성장 단계로 설명한다.

## 단계

| 단계 | 의미 | 특징 |
|---|---|---|
| L0 | 단순 응답 | 명령을 주면 결과만 돌려준다. |
| L1 | 세션 안 기억 | 현재 대화 안에서는 맥락을 유지하지만 세션이 끝나면 사라진다. |
| L2 | 다단계 계획 | 목표를 여러 단계로 나눠 실행한다. |
| L3 | 세션 간 학습 | 경험이 다음 세션으로 넘어가며 행동이 달라진다. |
| L4 | 자율 진화 | 스킬과 전략을 스스로 조정한다. |
| L5 | 헌법 수준 자기 수정 | 시스템이 자기 원칙까지 바꿀 수 있다. |

현재 실무에서 쓰는 대부분의 에이전트는 L1-L2에 머문다.
L3부터는 세션을 넘는 기억, 평가, 안전 장치가 필요하다.

## 사람의 역할 변화

자율성이 올라가면 사람의 역할도 바뀐다.

- 명령자
- 교사
- 코치
- 상담자
- 파트너
- 헌법 수호자

핵심은 단계 승급이 시간 경과로 자동 발생하지 않는다는 점이다.
능력과 신뢰를 모두 검증해야 하며, 위험한 상황에서는 낮은 단계로 퇴행하는 것이 정상이다.

## brain 적용

이 단계 모델은 AI 개발 하네스를 설계할 때 목표 수준을 명시하는 용도로 쓸 수 있다.
예를 들어 `planning`만 자동화하는 하네스는 L2에 가깝고, PR 리뷰 학습을 다음 스킬에 환원하는 하네스는 제한된 L3 성격을 가진다.

조코딩의 OpenAI 인터뷰는 이 단계 모델을 제품과 조직 전략으로 읽는 실무 관점을 보강한다.
모델이 더 긴 작업을 수행하고 도구를 연결할수록 [[ai-native-startup-strategy]]에서는 작은 팀, 고객 워크플로우, forward-deployed engineer의 중요성이 커진다.

하용호의 AI 시대 전문성 발표는 자율성 증가에 따른 운영 조건을 보강한다.
에이전트가 더 많은 산출물을 만들수록 사람은 모든 중간 결과를 이해하기보다 [[ai-verification-layer]]를 설계하고 유지해야 한다.
