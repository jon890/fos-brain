# 문서 파싱 품질 평가 방법론

문서 파싱과 OCR 출력의 품질을 재는 방법은 하나가 아니다.
비용과 깊이가 다른 평가를 조합해 텍스트 정확도, 구조 보존과 RAG 입력 적합성을 따로 확인한다.

## 평가 스펙트럼

- **회귀 테스트**: 이전 출력과 같은가·다른가를 결정적으로 검사한다.
  - 상시 CI에서 가볍게 실행할 수 있다.
  - 이전과 현재가 모두 틀리면 품질 저하를 알 수 없다.
- **정답 테스트**: 사람이 확정한 golden 출력과 비교해 절대 품질을 확인한다.
  - 기존 출력이 틀린 경우에도 개선 여부를 판별할 수 있다.
  - 정답지를 만들고 유지하는 비용이 든다.
- **NED**: 예측과 정답 사이의 편집 거리를 정량 점수로 측정한다.
  - 순수 텍스트와 읽기 순서 비교에 적합하다.
  - 표의 행·열 관계와 레이아웃 손실은 별도로 평가해야 한다.
- **구조 지표**: 표 셀 F1이나 TEDS처럼 표 구조와 셀 대응을 측정한다.
  - 텍스트 종합 점수에 묻히는 셀 누락과 위치 변경을 찾는다.
- **LLM as Judge**: 원본 표현과 변환 Markdown을 함께 읽고 의미 품질을 루브릭으로 평가한다.
  - 구조 보존, 읽기 자연스러움과 RAG 입력 적합성처럼 정적 지표가 놓치는 품질을 본다.
  - 비용과 비결정성 때문에 반복 실행과 사람 검토가 필요하다.

## 원본 문서와 Markdown 평가 루프

Judge가 읽을 수 있는 원본 표현과 변환 Markdown을 한 쌍으로 만든다.
PDF와 이미지는 렌더링된 페이지를 사용할 수 있고, Office와 HWP 계열은 원본 렌더링과 추출된 구조 정보를 함께 제공할 수 있다.

평가는 다음 순서로 구성한다.

1. 파일 형식과 콘텐츠 유형을 분류한다.
2. 파서, OCR 설정과 표 직렬화 방식별 변환 후보를 만든다.
3. NED와 구조 지표로 명백한 회귀를 먼저 검사한다.
4. LLM as Judge가 의미와 구조 보존을 루브릭에 따라 채점한다.
5. 낮은 점수와 평가 불일치 사례를 사람이 검토한다.
6. 실패 사례를 데이터셋과 루브릭에 환원해 다음 실험에서 다시 평가한다.

Judge 결과는 종합 점수 하나보다 평가 축별 점수와 근거를 구조화해 저장한다.

- 내용 누락과 중복
- 원문에 없는 내용 추가
- 제목 계층과 읽기 순서
- 표의 헤더, 행·열 관계와 병합 셀 의미
- 수식, 목록, 각주와 이미지 설명 보존
- Markdown 문법의 유효성
- chunk로 나뉘어도 의미를 이해할 수 있는지

## 표 변환 전략을 평가하는 질문

표는 Markdown 문법으로 만들었다는 이유만으로 RAG에 적합해지지 않는다.

- 다단 헤더가 각 데이터 셀과 연결되는가
- 병합 셀의 범위와 의미가 남아 있는가
- 행과 열을 바꿔 읽지 않는가
- 표가 chunk 경계에서 나뉘어도 헤더 맥락이 유지되는가
- 복잡한 표는 Markdown 표, HTML 또는 자연어 직렬화 중 무엇이 더 적합한가

정답은 파일 형식과 표 구조에 따라 달라질 수 있다.
따라서 하나의 표현을 고정하기보다 동일 문서에 여러 변환 전략을 적용하고 같은 루브릭으로 비교한다.

## LLM as Judge의 안정성 보완

- 정적 검사와 golden 평가를 앞단에 두어 Judge가 모든 오류를 책임지지 않게 한다.
- 여러 번 평가한 중앙값이나 합의 결과로 단일 호출의 편차를 줄인다.
- 장점을 먼저 요약하게 하기보다 누락과 구조 손실을 먼저 찾게 해 점수 부풀림을 줄인다.
- 낮은 점수뿐 아니라 Judge 간 판단이 크게 갈린 사례도 사람 검토 대상으로 보낸다.
- 모델과 프롬프트 버전을 기록해 평가 기준이 바뀐 시점을 추적한다.

## 조합 원칙

- 회귀 검사는 자주 실행하고, golden과 Judge 평가는 변경 후보와 릴리스 전에 깊게 실행한다.
- 정량 지표가 못 보는 의미와 구조 품질을 Judge가 보완한다.
- Judge가 내린 점수만 저장하지 않고 판단 근거와 실패 유형을 다음 실험 입력으로 남긴다.
- 문서 파싱 품질과 최종 RAG 답변 품질을 같은 것으로 표현하지 않는다.
  파싱 평가는 신뢰할 수 있는 입력을 만드는 선행 계층이다.
