# 코드 리뷰 게시를 한 리뷰로 합치기

## 질문

인라인 리뷰와 요약 댓글을 2회로 나눠 게시하는 방식과 한 리뷰로 합치는 방식 중
어느 쪽이 정리 방식까지 포함해 나은지 확인했다.

## 관찰

- 저장소 8곳 중 합쳐진 형태가 1곳이고 나머지 7곳이 2회로 나뉜 형태였다.
- 요약을 리뷰 본문으로 옮기면 제출된 리뷰를 지울 수 없어, 정리 방식이 삭제에서 접기로 강제된다.
- 7곳을 합치는 과정에서 함정 세 항목이 나왔다.
- 저장소마다 갈리는 축이 여덟이었다. 실행 방식, 프롬프트 위치, 요청 본문 전달,
  정리 방식의 기존 결정, 개행 보정 스텝, 파일 접근 경로, 목록 조회와 봇 로그인 표기다.

## 이 노트의 한계

실측 대상 저장소의 이름을 적지 않는다. 사내 저장소가 섞였는지 확인할 수 없다.
축과 관찰만 남기며, 정리한 결과는 [[ai-code-review-github-actions]]가 담는다.
