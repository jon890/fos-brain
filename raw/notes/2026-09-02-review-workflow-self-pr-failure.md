# 리뷰 워크플로를 고치는 PR 자체가 실패하는 함정

## 질문

리뷰 합치기를 여섯 곳에 적용했고 그중 다섯 곳의 PR 에서 리뷰가 실패했다. 그 원인을 확인했다.
처음에는 변경이 워크플로를 깨뜨린 것으로 판단해 로그를 파고들었다.

## 관찰

- `claude-code-action` 은 워크플로 파일이 기본 브랜치의 것과 같아야 앱 토큰을 내준다.
- 그래서 그 파일을 고치는 PR 은 `App token exchange failed: 401` 로 떨어진다.
- 액션이 오류 문구에 이런 경우는 정상이니 무시하라고 적어 둔다.
- 머지되면 기본 브랜치와 같아져 다음 PR 부터 정상 동작한다.
- self-hosted CLI 방식은 앱 토큰을 쓰지 않아 이 함정이 없다.

## 이 노트의 한계

실측 대상 저장소의 이름을 적지 않는다. 사내 저장소가 섞였는지 확인할 수 없다.
정리한 결과는 [[ai-code-review-github-actions]]가 담는다.
