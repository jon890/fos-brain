# 세션 → durable 지식 추출 기준

추출 sub-agent 가 정제된 세션 transcript 를 읽고 brain 후보를 뽑을 때 따르는 기준이다.
fos-brain 의 "6개월 뒤에도 검색해서 유용한가" 원칙을 세션 맥락에 맞춰 구체화한다.

## 세션 추출의 핵심 함정

세션은 **일회성 작업의 연속**이다 — 디버깅, 탐색, 특정 파일 수정, 한 번 쓰고 버릴 명령.
그래서 "이 세션에서 **한 작업**"을 그대로 옮기면 brain 이 일회성 기록으로 오염된다.

뽑아야 하는 것은 작업 자체가 아니라 **그 작업에서 배운 재사용 가능한 것**이다.

- 나쁜 후보: "docu-parser 의 config.py 에서 timeout 을 30 으로 바꿨다" (일회성, git 으로 자명)
- 좋은 후보: "이 라이브러리는 기본 timeout 이 너무 짧아 대용량 입력에서 끊긴다 — 늘려야 한다" (재사용 교훈)

판단 질문: **"이 항목을 6개월 뒤 검색하면 유용한가, 아니면 그때 코드·git 을 보면 되나?"** 후자면 버린다.

## 넣는다 (durable)

아래 유형을 **고루** 본다. 한 유형에 쏠리지 않게 한다.

- **개념·정의** — 세션 중 새로 배운 개념, 용어, 이론, 도메인 모델.
- **도메인 지식** — 한 분야의 구조·관계·지형 (제품군, 시장, 조직, 기술 스택 맥락).
- **결정과 근거** — 무엇을 왜 그렇게 정했나 (트레이드오프, 채택·기각 사유). 세션의 토론에서 자주 나온다.
- **패턴·방법** — 재사용 가능한 접근, 설계, 작업 방식.
- **함정·교훈** — 실패·디버깅에서 얻은 회피법. 아래 편향 경고를 함께 본다.
- **인물·개체** — 사람, 프로젝트, 목표 같은 entity.
- **개인 기록** — 일지·목표·취향. 이 brain 은 기술에 한정되지 않은 범용 brain 이다.

## 빼낸다 (일회성·자명·다른 곳)

- **특정 파일·코드 세부** — 함수 위치, 변경 이력, 특정 라인 수정 → git 으로 자명. 버린다.
- **일회성 업무 기록** — 특정 PR·plan 으로 끝난 작업, 특정 시점의 버그 실측 → 버린다.
- **이미 널리 알려진 원칙의 단순 사례** — 새 인사이트가 아니면 durable 가치 낮다.
- **실행 절차** → skill 로 (brain 아님).
- **행동 규칙·취향 지시** → CLAUDE.md 로 (brain 아님).
- **세션 한정 상태** — "지금 서버를 띄웠다" 류 → 버린다.

## 함정 편향 경고 (필수)

LLM 은 "함정·교훈"이 가장 식별하기 쉬워서 거기로 쏠린다.
한 세션에서 함정만 여러 개 뽑고 정작 그 세션이 가르친 **개념·도메인 지식·결정**을 빠뜨리지 않았는지 자문한다.
함정은 일곱 유형 중 하나일 뿐이다.

## 정확성·출처

- 출처 있는 사실인가, 세션 중의 추측인가 → 추측이면 후보에 "미검증" 표기.
- 사용자 정정 여지 큰 주관 판단인가 → 표기해 미리보기에서 확인받게 한다.
- 정제 과정에서 tool 출력이 절단됐으므로, 근거가 빈약하면 무리하게 단정하지 않는다.

## 네임스페이스 1차 추정

세션 프로젝트 경로로 거칠게 추정한다 (최종 확정은 사용자 확인).

- 개인 레포(`/personal/`, obsidian) → `public` 또는 `private`.
- 회사 업무 레포(`/projects/`, 사내 도구) → `work`.
- 회사 운영 세부(내부 URL·사내 시스템·미공개 아키텍처)가 있으면 `work` 로 보수적 분류.
- 애매하면 `unknown` 으로 두고 미리보기에서 사용자에게 묻는다.

## 후보 출력 스키마

추출 agent 는 각 세션에서 아래 JSON 구조로만 반환한다 (durable 후보 없으면 빈 배열).

```json
{
  "candidates": [
    {
      "title": "후보 제목 (kebab-case 아닌 자연어)",
      "type": "concept | topic | entity",
      "summary": "한 줄 정의",
      "key_points": ["재사용 가능한 핵심 1", "핵심 2"],
      "namespace_guess": "public | private | work | unknown",
      "durability_reason": "왜 6개월 뒤에도 유용한가 (한 줄)",
      "evidence": "세션의 어떤 맥락에서 나왔는지 (출처 추적용)",
      "verified": true
    }
  ]
}
```

- `verified: false` 면 세션 중 추측·미확정 항목 — 미리보기에서 확인 대상으로 표시.
- 후보가 없으면 `{"candidates": []}` 를 반환한다. 억지로 채우지 않는다.
